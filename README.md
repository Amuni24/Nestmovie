# Nestmovie
This project is a movie discovery website that allows users to search and explore movies by title, genre, rating, and release date. Users can view movie details, discover popular and recommended movies, and save movies to a personal watchlist. The system makes it easier for users to find movies and keep track of what they want to watch.<br/>
